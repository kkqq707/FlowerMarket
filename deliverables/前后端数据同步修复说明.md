# 前后端数据同步修复说明

核验日期：2026-10-03。管理端和小程序后端都连接本机同一个数据库，差异主要来自前端演示数据兜底、筛选词不一致、刷新时机和接口筛选条件遗漏。

## 已修复

| 范围 | 修复内容 |
| --- | --- |
| 首页、分类、购物车推荐 | 使用后台真实商品；接口失败显示重试或空状态，不再自动替换成本地演示商品。 |
| 商品筛选 | 场景、赠送对象、色系从后台保存的实际标签生成，保留自定义值；分类包含子分类；搜索支持商品名称、花材、关键字和商品 ID。 |
| 商品销量和库存 | 列表与详情统一显示实际销量加配置虚拟销量；规格库存为 0 时不再回退成商品总库存。 |
| 页面刷新 | 首页、分类、商品详情再次显示时重新读取数据；管理端返回已缓存的商品列表时重新取数。 |
| 管理端商品状态 | 出售中、仓库中、已售罄、警戒库存、回收站分别筛选；标签数量与列表使用同一组商品、分类、关键词和花礼标签条件。 |
| 商品导出 | Excel 导出使用与管理端花礼列表相同的筛选条件和价格、库存、销量。 |
| 个人资料 | 进入页面重新读取资料；保存后重新读取完整资料并更新共享状态，同步昵称和头像。 |
| 订单列表 | 快速切换状态时发起新请求；旧请求的成功或失败结果不会覆盖当前状态的数据。 |

## 验证结果

- 小程序测试：54 项通过；微信小程序编译通过。
- 管理端测试：14 项通过；管理端编译通过。
- 后端本次定向测试：11 项通过；管理端、小程序后端打包通过。
- 实际接口：12 件商品、9 个分类、23 个筛选值，257 项核对通过，覆盖商品列表/详情/规格价格库存、销量、分类、标签、花材搜索、预算和空结果。
- 本地数据库只读核验：21 项管理端与小程序查询比较通过，确认管理端在售商品与小程序商品一致，状态数量与筛选结果一致。
- Excel 文件内容核验通过，确认导出条件、价格、库存和销量。
- 两个本地后端已重新启动并加载最终修改。
