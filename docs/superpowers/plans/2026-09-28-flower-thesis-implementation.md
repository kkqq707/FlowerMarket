# 花卉论文目标功能实施计划

> 对应已确认的花材批次、保鲜与配送联动设计，以及养花指南设计。实施时保留旧商品的 SKU 路径，数据库迁移只增不删。

## 任务 1：花材数据与迁移

1. 检查现有花卉模型、DAO、SQL 命名、订单行结构，写批次分配的失败测试。
2. 新建花材、批次、配方、订单分配模型与 DAO，新增幂等 SQL 迁移及演示数据。
3. 验证数据库字段约束、演示商品配方映射和迁移重跑安全性。

## 任务 2：库存事务与订单状态

1. 实现花材/批次/配方管理服务及参数校验，测试不足、到期日、跨批次、重复操作。
2. 在订单创建事务中按交付日锁定花材；取消和超时释放；首次制作时消耗。
3. 保留现有 SKU 库存和配送容量逻辑，验证异常导致整体回滚。

## 任务 3：管理端

1. 增加花材库存、批次入库/盘点、临期与低库存视图及配方维护入口。
2. 商品编辑与列表展示批次开关/配方状态；未启用历史商品标记待配置。
3. 养花指南复用文章编辑器，限制分类与权限，构建后台。

## 任务 4：小程序

1. 增加养花指南列表/详情 API 与页面，首页和商品详情加入入口。
2. 商品详情展示参考观赏期，订单提交显示花材不足的服务端错误。
3. 保持现有预约配送、顶部导航和花间集视觉，构建小程序。

## 任务 5：验证交付

1. 运行后端相关单元测试、模块编译和前端构建。
2. 检查 SQL 迁移及页面实际体验；无法连接的环境明确记录未实测项。
